# K4 尾部复制：标量展开与分散存储

基线固定为上游 138dcac，源码 SHA-256 `08400a7659134bf7bee3b14df24fc919537c9fef634d1b580bf66fba0b112357`。
本轮 pull 无新提交，默认源码、提交包和正式编译命令保持原样，未 push。

K4 每行复制先处理四平面向量块，再复制 `ncp % 4` 个标量，其中 `ncp = KW + 255 + sh`。
实际热路径在 k4 函数的标签 71；旧 K4_CP 宏没有调用，不优化该死宏。

- direct：按余数是否为 1/2 提前跳出，展开最多三次加载/存储。
- bits：利用余数范围 0..3，检查位 1 和位 0，省掉比较指令。
- scatter：保留零余数跳过，以 WHILELO 创建掩码，一次 LD1W 加载有效标量，INDEX 用平面字节距构造偏移，ST1W 分散写入各平面。

所有候选仅改标量尾部；整向量/谓词尾块复制、FMA、预取、调度、分派均不改。
x13/x20/x24 在旧循环后的值不再需要：后续复制和计算入口会重新设置，条件判断不依赖旧 SUBS 标志。
scatter 的 z1 由后续复制或 K4_STEP 覆盖；p4 下次使用前重新初始化。
基线仍要求 SME_FA64 和 64 字节 SVL，未放宽硬件判断。

标量候选的 12,736 项模型核对 KW 3..400、16 种对齐下的有序读写地址；scatter 的
6,368 项模型核对掩码后有效地址及不同平面的不重叠性。最大有效偏移在 32 位内，
INDEX/散写使用字节偏移，不额外乘 4。模型只证明该区间的地址等价，不证明所有汇编访存。
