# v56 mixed FMOPA/FMLA throughput diagnostic

The register-window experiment reduced L1-load events without a stable speedup.
This independent arithmetic-only probe measures how much vector FMLA can
overlap the four-FMOPA step used by a rolling pair. It is a standalone diagnostic,
not a convolution implementation, reference validator or submission artifact.

Generated by `tools/gen_v56_mixed_probe.py`. Each step has four FP32 FMOPA on
the four ZA tiles and N FMLA on independent accumulators, interleaved across
those FMOPA instructions. Pure-vector controls have no FMOPA. Four steps are
unrolled per counted iteration, with 1,000 warmup iterations and 1,000,000
measured iterations. Operands are nonzero and accumulation stays finite.
Measure one and 38 threads, three rounds, using CNTVCT/CNTFRQ. Report nanoseconds
directly; cycle values explicitly normalize to 1.55 GHz rather than assuming
the PMU has identified every instruction's physical latency.

## Predicated vector FMLA

**1582651**, cn20483, 2026-09-13 02:17:13–02:17:20, succeeded with all 84 timing
records. This FMLA form matches K33's predicated vector multiply-add. One-core
and 38-core results agree closely. At 38 cores:

| Four FMOPA plus N FMLA | ns/step | Normalized cycles/step |
| --- | ---: | ---: |
| N=0/2/4/6/8 | about 5.1616 | about 8 |
| N=10 | 6.4519 | 10 |
| N=12 | 7.7423 | 12 |
| N=16 | 10.3232 | 16 |
| N=18 | 11.6134 | 18 |

Pure-vector N=8/16/18 takes about 4/8/9 normalized cycles. Consequently the
mixed loop does not have unlimited free vector throughput, and the effective
budget differs from the pure-vector control. This is a measured behavior of
these instruction sequences; it does not uniquely identify physical ports,
issue widths or the bottleneck in every real kernel.

Raw source hash/log and the strict summary are under
`results/v56/experiments/mixed-throughput/`. The generic source is reproduced
byte-for-byte by running the generator without flags.

## Indexed scalar FMLA follow-up

The existing four-chain pair uses indexed scalar FMLA, not K33's predicated
vector form. The generic result must not silently stand in for that opcode.
The `--indexed` generator creates a separate source/directory, using alternating
input vectors and coefficient lanes 0..3 just like the four-chain pair. Additional
coefficient registers cover the N>8 diagnostic cases. Job **1582779** requests
cn20483 for this check; its result is recorded separately under
`results/v56/experiments/mixed-throughput-indexed/`.

The proposed [five-row, three-way folded group](k5-triplet-design.md) is still
a design, with no performance claim. Its paired four-row fold must respect the
indexed-FMLA budget as well as real loads, coefficient packing, output events,
state transfers and cache costs.
