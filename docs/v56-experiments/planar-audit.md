## 上游并行打包

上游默认按打包表大小选 mode 3（并行按组放行）或 mode 1（主线程按组打包）。
mode 3 以原子递增唯一认领 chunk，组计数使用 acquire/release，消费者检查自身组和
共享 R 的所属组是否就绪；静态检查未发现旧路径的重复写问题进入这两个默认模式。
每次调用仍重建全部系数，阈值依据打包元素数，未发现精确公开尺寸特判。
旧 `CONV_PACKSER=0` 仍调用会重复写 chunk 的 `roll_pack_all`，数据竞争问题未消除。
