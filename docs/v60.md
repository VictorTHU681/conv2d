# v60 汇总发布

本轮接续上游 v59 `364b46d`，将整晚本地 v56 实验中已通过验收的优化和正确性修复汇总为 v60。
本地多次实验提交不单独递增发布版本。历史 `docs/v56*`、`results/v56` 保留原名，
其中的“当前”“未 push”仅描述各自检查点，最新发布状态以本页为准。

采用源码 SHA-256：`ebf36923518cb809ae5e65001a700de30b0415956f1d0420a2dffcae45684026`。
K9 加载复用、K5 分组及较短任务块、每次调用的形状相位预计算、四切片 ZA 传输均保留。
同时修复输入前缀/尾部读取越界、可选打包模式重复写入、末尾条带输出写竞争、
预热输出游标的 C 指针形成及形状/线程切换时的 `pstart` 容量越界。
每次调用重新构建系数、计算全部输出，保持原有浮点累加顺序。

上游 v59 的提交历史、笔记、作业脚本和结果全部并入。其 K4 EXT、K9 对齐和 kf 共享
已经在本地隔离对照，未取得足以采用的稳定收益，因此合并时保留当前已验收的源码和包。
这项选择不是声称原始 v59 有性能退化；最终对比以本次直接原始基准结果为准。
对应证据：[K4 EXT/对齐](v56-experiments/k4-ext.md)、[kf 共享](v56-experiments/kf-share.md)。

```sh
gcc -O3 bench_conv.c conv2d.c -o conv2d_test -lm -fopenmp
```

线程/形状切换、1,305 项状态及 224 项保护页检查；原版越界有 ASan 阳性对照。

## 提交包与边界

- `submissions/conv.zip` 为普通包；`conv_nf3.zip` 为三链对照；`conv_diag.zip` 只供诊断。
- 当前包哈希见 `results/v60/packages.sha256`；包内程序与服务器验收包的对比见 `results/v60/archive_audit.txt`。
- 未发现公开完整尺寸特判、答案缓存或按计时阶段少算。有限测试不构成全部输入安全或完整赛事合规证明。
- 仓库题面没有明确授权额外 HBM 参数；诊断包含环境/调用阶段探针，不作正式合规替代。
- 外部多个调用者并发、分配失败处理、固定 64 字节 SVL 仍有适用范围限制。详见 [合规审查](v56-compliance.md)。

本轮发布后停止工作。以后有通过验证的性能优化，就汇总 push 并收尾，不无限迭代。
