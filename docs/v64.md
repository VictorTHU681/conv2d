## 采用的优化与直接对照

K5 输入复制的标量余数仅为 0..2，原来的计数循环改为一次复制，余数为 2 时再复制一次。
省去循环控制与不再需要的游标更新；有效输入读取范围、FMA 顺序和输出映射不变，
保留 v62 的完整块穿插与输出预取。源码 SHA-256：
`0136da05ea4658fb5792412e95baaec0e38ff299b176e5de681f228bca88da93`。

作业 **1590007**，cn20491，未修改的原始基准，六轮 AB/BA、每进程五次计时；
下表为进程平均 GFLOPS 中位数的直接比例，不叠加历史收益。

| 卷积核 | DDR 对 v63 | HBM 对 v63 |
| --- | ---: | ---: |
| 39×39 | -0.03% | +0.27% |
| 41×41 | **+0.86%** | **+0.62%** |
| 55×55 | -0.03% | +0.09% |
| 81×81 | +0.07% | -0.04% |

41×41 的 DDR 六轮均正、HBM 五轮正；HBM 有一轮 -3.31% 回退。其他形状不执行 K5，
不把它们的微小变化归因于这项优化。全部离群值保留，包括 HBM39 单轮 -7.77%。
[完整原始对照](../results/post63/k5-tail/confirm_summary.md)。
