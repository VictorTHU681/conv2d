# K4 输出事件的提取、清零和存储顺序

基线仍是上游138dcac/08400a76，不组合待复验的带索引存储。
K4每个tile的输出事件包含九条指令：四次MOVA读取ZA切片，一次ST4W输出，四次MOVA写零清除已读取切片。

- clearfirst：四次提取后先完成四次清零，再输出。
- paired：每次提取一个切片后立刻清除该切片，四对完成后输出。

每个切片均先读后清零，所有向量在存储前已经提取；下一tile重用z0..3前已经完成本tile的ST4W。
所有清零在下一输入行开始前完成，不延迟到其他行，不改变浮点累加或输出映射。
所有九条原指令每组恰好出现一次，未改变分派、打包或工作量。
