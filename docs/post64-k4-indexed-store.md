# K4 向量复制的带索引存储

在固定上游138dcac/08400a76上独立试验，不组合前轮被拒绝的复制/加载调度改动。
原四平面复制用四条ST1W和三条ADD串行生成平面地址。新方案用ST1W的标量索引寻址：

1. 平面0写基址，平面1用x3索引。
2. 临时寄存器计算2*x3并写平面2。
3. 再加x3得到3*x3并写平面3。

每块仍四次完整向量存储，地址计算由三条减为两条。SVE单字标量索引采用LSL #2，
因此只把传入汇编的A.TSB字段换成TSB/4；C侧分配、平面指针、首行复制等仍使用原字节TSB。
剩余使用x3的旧地址ADD全部补LSL #2，标量尾部地址也保持原样。

- full：仅替换主计算中穿插的整块复制，序言/串行复制保留原流程。
- all：同时替换序言向量尾块与小KW串行整块复制。

向量尾块仍保存全部16个通道，包含谓词加载产生的零，不缩减或新增有效写入范围。
临时寄存器分别选x24或x23，避免覆盖目的基址；序言的x24尾块计数保持到后续游标更新。
没有新增访存或浮点运算，没有按公开完整尺寸特判。19104项模型检查有序存储地址和
剩余字节步进等价；模型不能代替实际汇编的保护页测试。
