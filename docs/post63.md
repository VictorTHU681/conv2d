### 结论：不采用无前缀组合

| KH | DDR 组合 / v62 | HBM 组合 / v62 |
| --- | ---: | ---: |
| 39 | +0.17% | -0.14% |
| 41 | -0.05% | -0.08% |
| 55 | +0.34% | +0.33% |
| 81 | -0.19% | -0.12% |

KH41 的配对正向轮次仅 DDR 4/6、HBM 2/6；KH81 分别 1/6、2/6。KH55 六轮均正，但
该形状不执行 K5，不能归因于减少前缀拷贝，也不足以抵消其他用例回退。链接后的 K5
从 1,464 字节缩至 1,336 字节，18 个公共文本符号地址移动，编译器 helper 克隆和
roll_worker 的大小也改变；符号编号不保证克隆对应关系，不声称非 K5 机器码保持不变。

旧 v61 无前缀版直接对 v62 的 KH41 为 DDR -1.33%、HBM -0.98%，均 0/6 配对正向。
这排除了用旧候选覆盖上游新版的理由，历史对 v61 的收益不能叠加。
