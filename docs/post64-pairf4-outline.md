# PAIRF4 独立函数与四步展开

上一轮在新上游 `b6ea996 / 08400a76` 上组合 U4 没有足够的整体收益，已拒绝。
本轮固定同一上游，使用三个独立源码：

- baseline：原样上游。
- outlined：仅把 k16pairf4 声明改为 noinline、aligned(128)。
- outlined_u4：同样独立成函数，另保留已检查的短计算循环 U4 展开。

原函数会被内联到 roll_worker 中；独立后每次原 PAIRF4 调用增加真实函数调用边界，
可能带来寄存器保存、栈空间和调用开销，也改变布局。不能把候选收益预先归因于
某一项变化。分派条件、算术和内存访问逻辑在 outlined 单独候选中不变，U4 候选的
每输出 FMA 顺序、整块与标量余数边界沿用前轮检查；仍需服务器运行验证。

本轮没有新增运行期环境选项或输入尺寸特判。生产源码与三个发布包未替换。
源码哈希保存在 [清单](../results/post64/pairf4-outline/sources.sha256)，
[生成器](../tools/gen_post64_pairf4_outline.py) 验证去掉属性后可逐字节恢复各自的输入源码。
