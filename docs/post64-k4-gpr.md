- post：`ldr w23, [x13], #4`，五条循环体指令，相对gpr_loop每次少一条。
- pre：循环前先`sub x13, x13, #4`，循环中`ldr w23, [x13, #4]!`，五条循环体指令加一次设置；
  静态总条数和gpr_loop相同。结束时x13指向最后一个元素，其值在下一阶段重新初始化。
